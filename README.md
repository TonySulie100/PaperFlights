# ✈️ Paper Flights

A hand-drawn 2D paper airplane side-scrolling shooter built in Unity. Navigate through dynamic classrooms, hallways, and office environments while dodging hazards, collecting coins, and using tactical power-ups!

---

## 🎮 Key Features
* **Seamless Side-Scrolling:** Continuous background tiling with precision alignment.
* **Stackable Power-Up System:** Triple Shot, Shield, Magnet, and Rocket Launcher with live countdown text tracking.
* **Dynamic Wave Progression:** Defeat enemy wave quotas leading into a thrilling Boss confrontation.
* **Crystal-Clear 2D Audio:** Positioned camera audio architecture with centralized volume control.
* **Polished UI/UX:** Interactive main menus with hover/click SFX and an in-game scrollable changelog log.

---

## 🛠️ Built With
* **Engine:** Unity 6
* **Language:** C#
* **Platform:** Windows PC (.exe)
